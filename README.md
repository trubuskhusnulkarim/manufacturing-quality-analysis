Manufacturing Quality Analysis

Overview

A manufacturing quality analysis project focused on transforming raw data into meaningful insights.

Workflow

Data Cleaning → Data Analysis → Data Visualization → Key Findings

Data Cleaning: Cleaned and prepared raw data using Excel Power Query.

Data Analysis: Analyzed production, reject, defect, and process data.

Data Visualization: Built a dashboard using Pivot Tables and Pivot Charts.

Key Findings: Identified key patterns and quality issues from the analysis.

Tools

Microsoft Excel
